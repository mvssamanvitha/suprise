# A Little World for You

A small, Spider-Man-inspired romantic website foundation built with HTML, CSS, and vanilla JavaScript. The web patterns and characters are original CSS illustrations; the project has no external assets or dependencies.

## Run locally

1. Open this project folder in VS Code.
2. Open `index.html` directly in Chrome, or use the VS Code Live Server extension and choose **Open with Live Server**.
3. If using Live Server on its default port, open `http://127.0.0.1:5500/index.html` in Chrome.

The pages also work as local files because all stylesheet and script paths are relative.

## Try the opening

Choose **Come on in** to watch the web part and continue to `home.html`. With reduced motion enabled in your operating system or browser, the link skips the transition and opens the home page immediately.
